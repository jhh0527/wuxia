===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_5_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `――` `——` | **JSON·대사에 넣지 말 것** — 말끊김은 `...`, 박자는 `[short pause]` 또는 inputs 분리 (2_2 합성 시 자동 치환되나 억양 편차 가능) |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

제43장-종남산(終南山)으로

새벽빛이 채 퍼지기 전에 다섯은 길을 나섰다.

진무한이 앞서고, 한백강이 반 보 뒤에 섰다. 서령란은 세 걸음 간격을 두고 걸었고, 남궁린은 그보다 더 뒤에서 좌우를 살폈다. 청허진인은 맨 뒤에서 느린 걸음으로 따랐으나, 그 느린 걸음이 나머지 넷의 경공과 같은 속도라는 것을 아무도 이상하게 여기지 않았다.

종남산까지 이틀 길이었다.

진무한은 출발 전 한마디만 했다.

"하루 반."

한백강이 고개를 끄덕였고, 서령란이 입꼬리를 살짝 올렸다. 남궁린은 이미 짐을 단단히 묶고 있었다. 청허진인만이 아무 반응 없이 길을 바라보았다.

이틀 길을 하루 반으로 줄인다는 것은 단순히 빨리 달린다는 뜻이 아니었다. 큰길을 버리고 산길을 탔다. 마을을 끼지 않았다. 식사는 걸으며 먹었고, 쉬는 시간은 반 시진을 넘기지 않았다.

첫째 날 오전, 다섯은 관중 평야의 끝자락을 가로질렀다. 밀밭 사이로 난 좁은 길이 점점 높아지더니 바위가 드러나기 시작했다. 바람이 달라졌다. 평야의 따뜻한 바람이 아니라, 산에서 내려오는 서늘하고 마른 바람이었다.

진무한의 감각이 사방으로 펼쳐져 있었다. 삼십 장(丈) 안의 풀 한 포기, 돌 틈의 도마뱀, 먼 언덕 위의 까마귀까지. 회귀 이후 몸에 밴 습관이었다. 누가 따라오는지, 무엇이 기다리는지, 어디서 기운이 어긋나는지.

지금은 아무것도 없었다. 길은 깨끗했다.

그러나 깨끗한 길이 더 불안했다. 현무진인이라는 이름이 머릿속에서 떠나지 않았다. 전대 장문인. 화산을 떠난 자. 「환(還)」이라는 호를 가진 자. 전생에서도 그 이름은 들었으나, 얼굴은 본 적이 없었다. 이미 산에 묻혀 있었기 때문이다.

이 생에서는 달랐다. 그는 살아 있었고, 움직이고 있었고, 판(盤)을 쥐고 있었다.

진무한은 걸음을 늦추지 않았다.

오후가 되자 길은 본격적으로 산으로 들어갔다. 소나무가 빽빽해지고, 바위가 커졌다. 이따금 계곡을 건너야 했다. 한백강이 먼저 건너고, 진무한이 뒤를 따랐다. 서령란은 가볍게 뛰었고, 남궁린은 발소리 없이 넘었다. 청허진인은 도포 자락이 바위에 스칠 듯 말 듯 한 걸음으로 건넜다.

아무도 말이 없었다.

해가 기울기 시작할 무렵, 청허진인이 처음으로 걸음을 앞으로 옮겼다.

다섯의 대열이 미세하게 바뀌었다. 진무한의 감각이 먼저 알아챘다. 뒤에 있던 기운이 옆으로 온다. 고개를 돌리니 청허진인이 나란히 걷고 있었다.

한동안 말이 없었다.

소나무 그림자가 길 위에 비스듬히 누웠다. 바람에 솔잎이 흔들렸고, 그 사이로 저무는 햇빛이 금빛 점을 뿌렸다. 청허진인의 흰 수염에도 그 빛이 닿았다.

"사형을 만나면 내가 먼저 말을 걸겠다."

낮은 목소리였다. 바람에 흩어질 정도로.

진무한은 고개를 끄덕였다.

그것으로 충분했다. 그러나 청허진인은 멈추지 않았다.

"삼십 년이다."

진무한은 앞을 보았다.

"삼십 년 전에 사형이 산을 내려갔다. 내가 붙잡지 못했다."

솔바람이 불었다. 청허진인의 목소리는 변하지 않았다. 높아지지도, 떨리지도 않았다. 그러나 진무한은 알았다. 그 평온함이 삼십 년 동안 쌓인 것이라는 것을. 한 번도 내보이지 않은 것이라는 것을.

"…장문의 짐을 혼자 지셨습니까."

진무한이 물었다. 청허진인은 고개를 살짝 돌렸다. 제자의 눈을 보았다. 열다섯 살 소년의 눈이 아니었다.

"짐이라고 생각한 적은 없다."

거짓이었다. 진무한은 알았다. 그러나 그것이 이 노인의 방식이었다.

"다만."

청허진인이 말을 이었다.

"사형의 검이 어떻게 변했는지는 모른다. 그것이 걱정이다."

진무한은 다시 고개를 끄덕였다. 걱정이라는 말을 이 노인의 입에서 듣는 것은 처음이었다. 전생에서도, 이 생에서도. 화산의 최고위 원로가 걱정을 입에 올린다는 것은, 그만큼 앞에 놓인 것이 무겁다는 뜻이었다.

청허진인은 다시 반 보 뒤로 물러났다. 대열이 원래대로 돌아갔다.

한백강이 뒤를 돌아보았다. 진무한의 눈을 찾았다. 진무한은 시선으로 답했다 — 괜찮다. 한백강은 다시 앞을 보았다.

밤이 짧았다.

다섯은 산 중턱의 바위 그늘에서 반 시진만 쉬었다. 불을 피우지 않았다. 서령란이 품에서 마른 떡을 꺼냈고, 나누어 먹었다. 남궁린은 먹는 동안에도 칼자루에 손을 올려놓고 있었다.

진무한은 바위에 등을 기대고 눈을 감았다. 잠이 아니었다. 감각을 넓힌 것이었다. 산의 기운이 몸속으로 흘러들었다. 종남산이 가까워질수록 기운이 달라지고 있었다. 화산(華山)의 기운과 비슷하면서도 다른, 더 오래되고 더 무거운 것이 땅 아래에서 올라오고 있었다.

눈을 떴을 때 한백강이 옆에 앉아 있었다.

"형님."

한백강의 목소리가 낮았다.

"말해."

"진법이 있을 겁니다."

진무한은 고개를 돌렸다. 한백강의 눈이 어둠 속에서 차분하게 빛나고 있었다. 천마의 눈 파편이 깃든 그 눈은 보통 사람이 보지 못하는 것을 보았다.

"이미 느꼈습니까."

한백강이 말했다.

"반나절 전부터."

진무한은 짧게 답했다. 한백강은 고개를 끄덕이고 더 묻지 않았다. 그것이 이 사내의 방식이었다. 묻되 깊이 파지 않는다. 대신 옆에 선다.

진무한은 다시 눈을 감았다.

잠은 오지 않았다. 눈을 감으면 전생의 기억이 올라왔다. 종남산에 온 적은 없었다. 현무진인이라는 이름도 전생에서는 이미 사라진 이름이었다. 그러나 지금, 이 생에서는 그 이름이 모든 것의 중심에 있었다. 두 번째 판의 주인. 노인과는 별개의 기둥. 「환」이라는 호 아래 무엇을 감추고 있는가.

새벽이 왔다.

둘째 날 아침, 다섯은 다시 달렸다. 산길은 점점 가팔라졌다. 이끼 낀 바위, 쓰러진 고목, 마른 계곡. 사람의 흔적이 사라졌다. 나무꾼의 발자국도, 산짐승의 길도 끊겼다.

진무한의 눈이 좁아졌다.

길이 죽어 있었다. 자연스럽게 사람이 오지 않는 것이 아니라, 무언가가 사람을 밀어내고 있었다. 보통 사람이라면 이유 없는 불안감을 느끼고 발길을 돌렸을 것이다. 무공을 익힌 자라면 기운의 흐름이 어긋나 있음을 알아차렸을 것이다.

"산이 막혀 있군."

서령란이 낮게 말했다. 걸음을 멈추지는 않았다.

청허진인도 느꼈을 것이다. 그러나 아무 말 없이 걸었다.

오후가 되자 골짜기가 깊어졌다. 양쪽 벼랑이 솟아올라 하늘이 좁아졌다. 나무 사이로 스며드는 빛이 희미해졌다. 이끼가 두꺼워졌고, 공기가 축축해졌다. 발밑에 돌계단이 나타났다.

진무한이 멈추었다.

돌계단이었다. 사람이 깎은 것이다. 그러나 이끼가 두텁게 덮여 있었고, 군데군데 무너져 있었다. 아무도 돌보지 않은 지 오래되었다.

계단 위로 시선을 올렸다.

골짜기 안쪽, 벼랑 사이에 낀 듯한 자리에 도관(道觀)이 있었다. 아니, 있었던 것이 남아 있었다. 기와가 반쯤 무너졌고, 기둥이 기울어져 있었고, 문짝 하나가 땅에 떨어져 있었다. 담장은 허물어져 돌무더기가 되었다.

허물어진 도관.

"여기입니까."

한백강이 물었다.

청허진인이 앞으로 걸어 나왔다. 늙은 눈이 그 폐허를 바라보았다. 오랜 시간이 그 눈 위를 지나갔다.

"여기다."

두 글자에 삼십 년이 담겨 있었다. 진무한은 그 목소리의 무게를 들었다. 저 노인이 기억하는 이 도관은 이런 모습이 아니었을 것이다.

그러나 감상에 잠길 여유는 없었다.

다가갈수록 기운이 달라졌다.

진무한의 온몸에 소름이 돋았다. 검객의 직감이 아니라, 몸이 먼저 반응했다. 피부 아래 경맥이 저절로 긴장했다. 한매심법의 내공이 스스로 순환을 시작했다.

진법(陣法)이었다.

도관 주위에 깔려 있었다. 눈에 보이지 않았다. 그러나 기운으로는 선명했다. 마치 보이지 않는 벽이 도관을 둘러싸고 있는 것 같았다. 아니, 벽보다는 그물에 가까웠다. 밟으면 얽히는 그물.

남궁린은 한 걸음 뒤로 물러나 검자루에 손을 올렸다. 이 사내의 역할은 싸우는 것이었다. 진법은 다른 이들의 몫이었다.

도포 소매를 걷지 않았다. 손가락 하나 까딱하지 않았다. 그저 한 걸음을 내디뎠을 뿐이었다. 그런데 기운이 바뀌었다. 진법의 그물이 흔들렸다. 화산 최고위 원로의 내공이 진법의 표면을 스쳤다.

"이것은 사형과 내가 젊을 때 함께 연구하던 것이다."

청허진인의 목소리가 고요했다.

"내가 풀겠다."

진무한은 물러섰다. 한백강과 서령란도 반 걸음 뒤로 물러났다. 이 순간 앞에 설 수 있는 사람은 하나뿐이었다.

청허진인의 손이 움직이기 시작했다.

느렸다. 물속을 헤치는 듯한 손짓이었다. 그러나 그 느린 손짓 하나하나에 수십 년의 내공이 실려 있었다. 진무한의 눈에는 보였다. 노인의 손끝에서 기운이 가닥가닥 풀려 나가, 진법의 결을 하나씩 되짚고 있었다.

마치 옛 친구의 필적을 읽는 것 같았다.

삼십 년 전, 두 사람이 함께 연구하던 것이다. 같은 뿌리에서 출발한 진법. 한 사람은 화산에 남아 그것을 지켰고, 한 사람은 산을 내려가 그것을 바꾸었다. 지금 청허진인은 바뀐 그 결을 역으로 풀어가고 있었다.

시간이 흘렀다.

반 시진.

청허진인의 손이 마지막으로 한 번 돌았다.

기운이 풀렸다. 진법의 외층이 실타래 풀리듯 무너졌다. 보이지 않던 벽이 사라졌다. 도관까지의 길이 열린 것처럼 보였다.

그러나.

진무한의 눈이 좁아졌다.

아직이었다.

외층 아래에 또 하나의 층이 있었다. 외층이 사라지자 비로소 드러난 것이었다. 처음부터 이중으로 설계된 진법이었다.
