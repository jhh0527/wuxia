===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_5_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `――` `——` | **JSON·대사에 넣지 말 것** — 말끊김은 `...`, 박자는 `[short pause]` 또는 inputs 분리 (2_2 합성 시 자동 치환되나 억양 편차 가능) |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

제42장-세 번째 각성

화산 뒷산은 고요했다.

봄이 지나고 여름이 채 오기 전, 산등성이를 타고 올라온 바람이 소나무 사이를 빠져나가며 낮은 소리를 냈다. 폐관지로 향하는 돌길은 오래전 누군가 정으로 쪼아 만든 것이었으나, 이제는 이끼와 잡풀이 틈새를 메우고 있었다. 사람의 발길이 닿지 않은 지 오래였다.

진무한은 그 길 끝에 서서 돌문을 올려다보았다.

폐관지.

화산파가 대를 이어 전해 온 수련처 가운데 가장 깊고, 가장 외진 곳. 뒷산 절벽 아래를 파서 만든 석실은 바깥 소리가 닿지 않고, 안의 소리가 새어 나가지도 않았다. 벽은 화강암이었고, 바닥에는 얇은 먼지가 쌓여 있었다. 마지막으로 이곳을 쓴 이가 누구였는지는 기록에도 남아 있지 않다고 했다.

한백강이 반 발짝 뒤에 서 있었다.

진무한은 돌아보지 않았다. 다만 입을 열었다.

"사흘을 달라."

그것이 전부였다. 설명도, 이유도 덧붙이지 않았다. 한백강은 물어보지도 않았다. 그저 고개를 한 번 숙이고, 반 발짝 물러섰다.

진무한의 손이 돌문의 홈을 잡았다. 오래된 돌이 거칠게 손바닥을 긁었다. 힘을 주자 묵직한 마찰음과 함께 돌문이 안으로 밀려들어갔다. 석실 안쪽에서 차갑고 눅눅한 공기가 밀려 나왔다. 햇볕을 본 적 없는 돌의 냄새. 오래된 정적의 냄새.

진무한이 안으로 들어섰다.

한백강은 돌문 앞에 선 채 그 뒷모습을 보았다. 넓지 않은 어깨. 아직 스물하나의 뼈대. 그러나 걸음에는 흔들림이 없었고, 등은 곧았다. 마치 이 길의 끝에 무엇이 있는지 이미 아는 사람의 걸음이었다.

돌문이 닫혔다.

무거운 소리가 산 아래까지 울려 퍼질 듯했으나, 실은 그렇지 않았다. 두꺼운 화강암이 소리를 삼켰고, 이내 바깥에는 다시 바람 소리와 새 울음만 남았다.

한백강은 돌문 앞에서 물러나지 않았다. 등을 돌문에 기대지도, 그 앞에 앉지도 않았다. 서 있었다. 돌문을 바라보며, 아무 말 없이.

사형이 사흘을 달라 했으니, 사흘을 지키면 그만이었다.

석실 안은 어두웠다.

빛이라고는 천장 한쪽 구석에 뚫린 주먹만 한 환기구로 들어오는 실낱 같은 것뿐이었다. 그마저도 바깥 구름이 해를 가리면 사라졌다. 진무한은 어둠에 개의치 않았다. 눈을 감으면 빛이고 어둠이고 같은 것이었다.

바닥 한가운데 자리를 잡았다. 먼지를 털지도 않았다. 무릎을 꿇고, 허리를 세우고, 두 손을 무릎 위에 올렸다. 왼손 위에 소검을 놓았다.

소검.

검성(劍聖)이 남긴 검. 백 년의 세월을 검총 속에서 잠들어 있던 물건. 칼날의 길이는 한 뼘 반에 불과했으나, 그 안에 담긴 것은 칼날의 길이로 잴 수 있는 것이 아니었다.

검성이 평생을 걸어 모은 검의(劍意)의 최종 층.

검의란 검을 든 자의 뜻이다. 칼을 어디로 향하게 할 것인가. 무엇을 벨 것인가. 무엇을 지킬 것인가. 그 뜻이 충분히 깊고, 충분히 단단하면, 칼날을 떠나 기운 자체가 된다. 검성은 그것을 평생에 걸쳐 한 자루 소검 안에 응축해 두었다.

진무한의 손가락 끝에서 소검의 차가운 표면이 느껴졌다. 미세한 진동. 살아 있는 듯한 떨림. 아직 잠든 것이 남아 있다는 뜻이었다.

전생에서는 서른다섯에 도달했던 경지다.

열다섯 해를 더 살아야 닿을 수 있었던 곳. 피와 상처와 죽음의 그림자를 수없이 밟고서야 겨우 한 발을 올려놓았던 문턱. 그때의 기억이 아직 영혼 깊은 곳에 남아 있었다. 경맥이 찢어지는 고통, 단전이 뒤집히는 감각, 그리고 그 너머에서 처음 본 풍경.

지금 이 몸은 스물하나다.

근골은 젊고, 경맥은 넓되 아직 끝까지 열리지 않았다. 내공의 총량은 전생의 절반에도 미치지 못한다. 그러나 영혼은 달랐다. 전생의 끝까지 간 자의 영혼이 이 젊은 몸 안에 들어 있었다. 그 영혼이 기억하고 있었다. 검의의 최종 층이 어떤 모양인지. 어떤 온도인지. 어떤 무게인지.

그래서 가능하다고 판단했다.

사흘.

눈을 감았다. 호흡을 가라앉혔다. 단전 아래, 무혼(武魂)이 느리게 돌고 있었다. 두 번의 각성을 거친 무혼은 이전과 달랐다. 한 줄기 불씨 같던 것이 이제는 손바닥만 한 구(球)의 형태를 이루고 있었고, 그 안에서 느리지만 꾸준한 회전이 일어나고 있었다. 진무한의 내공 전부가 그 회전 속에 응축되어 있었다.

왼손 위의 소검에 의식을 보냈다.

응답이 왔다.

칼날 안쪽, 겹겹이 쌓인 검의의 층 가운데 가장 깊은 곳에서 미세한 공명이 일어났다. 마치 수면 아래서 무언가가 눈을 뜨는 듯한 느낌. 진무한은 서두르지 않았다. 의식의 끝을 가늘게 뻗어 그 공명에 닿았다. 건드리지 않았다. 다만 곁에 두었다.

무혼이 반응했다.

단전 안의 구가 한 바퀴 더 빠르게 돌았다. 소검의 공명에 끌린 것이다. 무혼과 검의 사이에, 보이지 않는 실 하나가 놓였다.

첫째 날이 시작되었다.

공명은 느렸다.

북소리가 아니라 맥박 같았다. 단전의 무혼이 한 번 돌 때마다 소검의 검의가 한 번 떨렸다. 처음에는 박자가 맞지 않았다. 무혼은 빠르고 검의는 느렸다. 마치 젊은 심장과 늙은 심장이 나란히 뛰는 것 같았다. 진무한은 그 어긋남을 억지로 맞추려 하지 않았다.

기다렸다.

시간의 감각이 희미해졌다. 석실 안에는 낮과 밤의 경계가 없었다. 환기구로 들어오는 빛이 한 번 밝아졌다가 어두워졌으니 해가 한 번 지나간 것이리라. 그 사이, 공명의 박자가 조금씩 가까워지고 있었다.

무혼의 회전이 느려지고, 검의의 떨림이 빨라졌다. 서로를 향해 다가가는 두 개의 파동. 첫째 날이 저물 무렵, 둘의 박자가 거의 겹쳤다.

거의.

아직은 아니었다. 그 '거의'와 '완전히' 사이의 간극이, 이 수련의 본질이었다.

진무한은 자세를 흐트러뜨리지 않았다. 땀이 등을 타고 흘렀으나 닦지 않았다. 호흡은 길고 가늘었다. 소검의 칼날이 손바닥 위에서 미세하게 떨리고 있었다. 금속이 내는 소리가 아니라, 검의 자체가 울리는 소리였다. 귀로 듣는 것이 아니라 뼈로 느끼는 진동.

둘째 날이 밝았다.

공명이 충돌로 변한 것은 둘째 날 밤이었다.

전조가 있었다. 무혼의 회전이 갑자기 한 박자 빨라졌다. 소검의 검의가 그에 맞추려다가 반 박자를 놓쳤다. 어긋남이 파동을 만들었고, 파동이 파동을 불렀다. 공명이 아니라 간섭이 되었다. 간섭이 증폭되었다.

충돌.

단전 안에서 무혼이 격렬하게 요동쳤다. 소검의 검의가 칼날 밖으로 넘쳐흘렀다. 두 힘이 진무한의 경맥 안에서 부딪혔다. 서로 다른 방향으로. 서로 다른 속도로. 서로 다른 성질로.

내공이 역류했다.

경맥 셋이 동시에 팽창했다. 어깨의 견정(肩井), 팔뚝의 곡지(曲池), 그리고 단전 바로 위의 기해(氣海). 셋이 동시에 부풀어 올랐다. 안에서 밖으로 밀어내는 압력이 벽을 때렸다. 진무한의 얼굴에서 핏기가 사라졌다.

터지면 폐인이 된다.

그것을 알고 있었다. 전생에서도 같은 고비를 넘긴 적이 있었다. 다만 전생에서는 이미 서른다섯의 몸이었고, 경맥의 탄성이 지금과 달랐다. 지금은 스물하나다. 경맥은 젊어서 유연하나, 내공의 총량이 감당할 수 있는 한계가 낮았다. 역류하는 힘을 온전히 받아내기에는 그릇이 부족했다.

이를 악물었다.

입술 사이로 피가 스며 나왔다. 잇몸이 아니라 혀를 깨문 것이었다. 통증으로 의식을 붙잡았다. 경맥이 팽창하는 압력을 의지만으로 억누르려 했으나, 의지로 되는 일이 아니었다. 무혼과 검의의 충돌은 의식 아래에서 일어나고 있었고, 그것은 진무한의 통제를 벗어나 있었다.

숨이 거칠어졌다. 등에서 땀이 아니라 증기가 피어올랐다. 석실 안의 온도가 올라갔다. 먼지가 바닥에서 떠올라 공중에 머물렀다.

경맥이 한계에 다다르고 있었다.

바로 그때였다.

돌문 너머에서, 한 줄기 기운이 밀려들어왔다.

차가웠다. 그러나 날카롭지 않았다. 겨울 새벽, 서리가 내린 풀잎 위로 첫 햇살이 스미는 것 같은 기운. 차갑되 부드러운. 단단하되 무겁지 않은.

한매심법(寒梅心法).

한백강이 돌문 사이의 머리카락만 한 틈으로 기운을 밀어 넣고 있었다.

어떻게 알았는가. 석실 안의 소리는 밖으로 새어 나가지 않는다. 돌문은 두꺼운 화강암이다. 그러나 한백강은 알았다. 사흘 내내 돌문 앞에 서서 한 발짝도 움직이지 않았던 그는, 돌의 진동을 느꼈을 것이다. 아니면 돌문 사이로 스미는 열기를 감지했을 것이다. 혹은 그저 — 알았을 것이다. 설명할 수 없는 방식으로.

한매심법의 기운이 진무한의 경맥에 닿았다.

역류하는 내공의 흐름 사이로, 차가운 기운이 끼어들었다. 밀어내지 않았다. 감싸지도 않았다. 다만 곁에 흘렀다. 팽창하는 경맥의 벽을 바깥에서 받쳐주듯, 차가운 기운이 얇은 막처럼 감쌌다.

압력이 줄었다.

완전히 사라진 것은 아니었다. 그러나 터질 듯하던 경맥의 팽창이 한 단계 가라앉았다. 견정과 곡지가 먼저 안정되었고, 기해의 압력도 서서히 낮아졌다.

역류가 가라앉았다.

진무한은 눈을 뜨지 않았다. 그러나 입술의 힘이 조금 풀렸다. 깨문 혀에서 흐르던 피가 멈추었다. 호흡이 다시 길어졌다. 거친 숨이 가늘고 고른 숨으로 돌아오는 데 반각(半刻)이 걸렸다.

돌문 너머의 기운이 조금씩 옅어졌다. 한백강은 필요한 만큼만 보냈고, 더 이상은 보내지 않았다. 그것이 호위의 분수였다. 수련은 안에 있는 자의 것이었고, 밖에 있는 자는 다만 무너지지 않도록 받칠 뿐이었다.

진무한은 한마디도 하지 않았다.

한백강도 한마디도 하지 않았다.

돌문 하나를 사이에 둔 침묵이, 어떤 말보다 많은 것을 담고 있었다.

셋째 날 새벽.

동이 트기 직전이었다. 산 너머로 아직 해가 올라오지 않은 시각. 하늘의 가장 어두운 부분이 남색에서 짙은 쪽빛으로 변하는, 밤과 새벽의 경계.

석실 안에서 무언가 바뀌었다.

소리는 없었다. 빛도 없었다. 그러나 바뀌었다. 돌벽에 스민 수기(水氣)가 일시에 증발했다. 천장의 환기구로 한 줄기 바람이 빨려 들어왔다가, 곧 석실 안에서 밀려나왔다. 마치 석실 자체가 한 번 숨을 들이쉰 것 같았다.

무혼이 세 번째로 각성했다.
