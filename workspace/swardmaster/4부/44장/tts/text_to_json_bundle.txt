===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_5_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

================================================================================

5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `――` `——` | **JSON·대사에 넣지 말 것** — 말끊김은 `...`, 박자는 `[short pause]` 또는 inputs 분리 (2_2 합성 시 자동 치환되나 억양 편차 가능) |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

제44장-도관(道觀)의 싸움

도관의 문 앞에 네 개의 검이 동시에 빛을 뿜었다.

쨍——

금속이 칼집을 벗어나는 소리가 하나로 겹쳤다. 넷이 일제히 뽑았으되 시차가 없었다. 그것은 우연이 아니었다. 같은 스승에게, 같은 호흡으로, 같은 검을 배운 자들만이 낼 수 있는 소리였다.

진무한의 눈이 좁아졌다.

'절정.'

넷 모두. 한 명도 빠짐없이.

기의 두께만이 아니었다. 검을 쥔 자세, 양발의 간격, 시선이 흐르는 방향까지 — 뿌리가 같았다. 화산의 정통 검결에서 갈라져 나온 변형이되, 그 변형의 방식이 하나같이 동일한 손을 거쳤음을 말해 주고 있었다.

세 번의 생을 살며 검을 다듬은 자. 현무진인(玄武眞人).

그가 직접 가르친 검이었다.

진무한은 숨을 짧게 끊었다. 생각할 시간은 한 호흡이면 족했다. 이 자리에서 가장 중요한 것은 도관 안쪽이다. 청허진인이 들어가야 한다. 그 앞을 막는 것은 무엇이든 — 누구든 — 치워야 했다.

"사조는 안으로!"

진무한의 목소리가 새벽 공기를 갈랐다.

"나머지는 넷을 맡아라!"

외침이 끝나기도 전에 청허진인의 도포 자락이 바람을 일으켰다. 노인의 몸이 허공을 가르며 도관의 정문을 향해 곧장 쏘아졌다. 나이를 잊게 하는 신법이었다. 발이 땅에 닿는 횟수가 셋을 넘지 않았다.

호위 하나가 몸을 틀었다. 청허진인의 경로를 읽은 것이다. 검이 비스듬히 올라갔다 — 문 앞을 가로막으려는 궤적.

허나 그보다 빨랐다.

스읍.

얇은 검기 한 줄기가 호위의 검 앞을 선으로 그었다. 공기가 갈라지며 찬 바람이 호위의 뺨을 스쳤다. 한 치만 더 나아갔으면 목이었다. 호위의 발이 멈췄다. 찰나의 주저, 그 사이로 청허진인의 등이 문 안쪽으로 사라졌다.

진무한이 소검을 천천히 들어올렸다.

"둘은 내가 맡겠다."

말은 뒤를 향했다. 한백강과 남궁린이 이미 검을 뽑아 든 채 좌우로 벌어지고 있었다. 서령란은 세 발짝 뒤, 지붕 처마의 그림자 아래에 서서 소매 속에 손을 넣고 있었다.

배치는 말보다 빠르게 갖추어졌다.

진무한이 정면의 둘을. 한백강이 좌측 하나를. 남궁린이 우측 하나를. 서령란이 후방에서 전체를 본다.

호위들은 동요하지 않았다. 청허진인을 놓친 것에도, 넷 대 넷이 아닌 배치에도 표정의 변화가 없었다. 그것이 오히려 위험했다. 감정이 아닌 임무로 움직이는 검은, 꺾이는 순간까지 흔들리지 않는다.

왼쪽의 호위가 먼저 움직였다.

아니 — 둘이 동시에.

협공이었다. 좌측에서 허리를, 우측에서 어깨를. 각도가 정확히 사십오 도씩 벌어져 있었다. 한 명이 막으면 한 명이 들어오는 구조. 교본 같은 합격(合擊)이었으되, 교본을 넘어서는 것은 검의 끝에 실린 변초(變招)였다.

좌측 검이 허리를 노리다가 찰나에 솟구쳤다. 턱을 향한 역참(逆斬). 동시에 우측 검은 어깨를 향하던 궤적을 버리고 팔목을 감아 들어왔다. 기본초에서 변초로의 전환이 눈에 보이지 않을 만큼 매끄러웠다.

예측 불가.

세 번의 생에서 현무진인이 다듬고 또 다듬은 변초. 한 생에서 얻은 검법을 다음 생에서 수정하고, 그다음 생에서 완성한 것이리라. 정통의 틀 안에서 가능한 모든 변형을 실험한 끝에 남은 것들. 그래서 예측이 어려웠다. 정파의 검으로 낼 수 있는 변화의 극한이었으니까.

그러나.

진무한의 검안(劍眼)이 변초의 근원을 읽었다.

'화산 정통의 변형.'

뿌리가 같다. 가지가 아무리 뻗어도 뿌리를 벗어나지 못한다. 현무진인이 세 번의 생을 살았다 해도 그가 손에 쥔 것은 결국 화산의 검이었다. 그리고 진무한 역시 — 화산의 검으로 시작하여 그 너머로 나아간 자였다.

소검이 허공에 반원을 그렸다.

좌측의 역참을 검등으로 흘리면서 동시에 검 끝이 우측의 팔목 감기를 찔렀다. 한 동작에 두 검을 처리한 것이 아니었다. 두 검의 변초가 어디로 향할지를 이미 알았기에, 그 도착점에 먼저 소검을 놓아둔 것이었다.

쨍.

우측 호위의 검이 크게 밀려났다. 진무한의 소검에 실린 힘이 아니라 각도였다. 변초의 종착점을 꿰뚫는 한 점에 검 끝을 놓으면, 상대는 제 힘으로 제 검을 밀어내게 된다.

뿌리가 같으면 끝이 보인다.

진무한은 내심 그리 읊조렸다. 감상이 아니었다. 확인이었다.

그로부터 이어진 교환은 빨랐다.

열 초식. 호위 둘의 합격에 금이 가기 시작했다. 서로의 검이 만들어야 할 그물에 구멍이 뚫렸다. 진무한의 소검이 그 구멍마다 정확히 한 번씩 찔러 넣어졌기 때문이었다. 구멍이 생길 때마다 호위들은 보(步)를 고쳐 메웠으나, 메울수록 발이 좁아졌다.

스무 초식. 합격이 풀렸다. 아니, 풀린 것이 아니라 풀어야 했다. 좁아진 발로는 합격의 간격을 유지할 수 없었다. 둘은 좌우로 흩어졌고, 그 순간부터 개인의 검이 되었다.

개인의 검은 합격보다 나았으되, 진무한 앞에서는 부족했다.

스물다섯 초식째. 좌측 호위의 검에서 떨림이 보였다. 변초를 꺼내려 할 때마다 진무한의 소검이 그 시작점을 찌르니, 변초 자체를 펼칠 수가 없었다. 검이 기본초로 돌아갈 수밖에 없었고, 기본초만으로 진무한을 상대한다는 것은 — 성립하지 않았다.

서른 초식.

진무한의 소검이 좌측 호위의 검을 감아 비틀었다. 작은 원이 큰 원을 삼키는 검결. 호위의 손목이 꺾이며 검이 반 바퀴 돌아 땅에 박혔다.

꺾였다.

검을 잃은 호위가 뒤로 물러서려 했으나 진무한은 쫓지 않았다. 쫓을 필요가 없었다. 검 없는 절정은 발톱 빠진 매와 같다.

우측 호위의 눈이 흔들렸다. 벗 하나가 꺾이는 것을 본 검은 어쩔 수 없이 무거워진다. 변초의 전환이 한 박자 늦어졌다.

사십 초식.

사십오 초식.

오십 초식째 — 진무한의 소검이 우측 호위의 어깨를 베었다.

깊지는 않았다. 그러나 정확했다. 검을 쥔 팔의 어깨. 근육이 갈라지면서 검을 쥔 손에 힘이 빠졌다. 호위가 이를 악물고 검을 바꿔 쥐려 했으나, 진무한은 그 시도조차 허락하지 않았다. 소검의 끝이 호위의 목 앞 한 치에 멈췄다.

"내려놔라."

낮은 목소리. 호위의 검이 돌바닥에 떨어졌다.

진무한이 숨을 내쉬었다. 가늘고 길게. 검 끝의 떨림은 없었으나, 오십 초식을 쉬지 않고 밀어붙인 것은 내공에 부담을 주었다. 절정 둘을 동시에 상대한 것은 이 몸의 나이에서는 무리에 가까웠다. 그러나 무리를 해야 할 때가 있고, 이 새벽이 바로 그때였다.

시선이 좌측으로 갔다.

한백강.

사형은 고전하고 있었다.

상대 호위의 검은 정통의 빠르기를 온전히 갖추고 있었고, 한백강의 검은 — 정통이 아니었다. 화산의 틀 안에서 움직이되 기저에 깔린 내공의 결이 달랐다. 마교의 암공(暗功). 그것이 한백강의 검을 묘하게 비틀었고, 동시에 묘하게 살렸다.

한백강은 밀리고 있었다. 검의 교환만 보면 그랬다. 호위의 검이 한백강의 검을 두 번, 세 번 쳐올릴 때마다 한백강의 발이 반 보씩 뒤로 물러났다. 어깨 위 도포가 한 줄 갈려 있었고, 왼쪽 소매에 붉은 기가 스며들고 있었다.

그러나 한백강은 무너지지 않았다.

마교 암공의 쓰임이었다. 검이 부딪힐 때마다 한백강의 내공이 호위의 검에 한 올씩 스며들었다. 음침한 기운이 아니었다. 오히려 아무것도 아닌 것처럼 얇았다. 그러나 그 얇은 것들이 쌓이면 검을 쥔 손의 감각이 흐려진다.

열 합 전만 해도 정확했던 호위의 변초가 스물 합을 넘기자 끝이 흔들리기 시작했다. 내공의 흐름에 이물이 섞인 것을 감지한 호위가 눈살을 찌푸렸다. 처음으로 표정이 바뀌었다.

"……네 검에 섞인 것이 무엇이냐."

한백강은 답하지 않았다. 입가에 희미한 미소만 걸쳐 있었다. 밀리면서도, 피를 흘리면서도 무너지지 않는 자의 여유. 그것이 상대를 더욱 조급하게 만들었다.

한백강은 버티고 있었다. 이길 수 있어서가 아니라, 상대를 흐트러뜨릴 수 있으므로.

우측 — 남궁린은 달랐다.

과묵한 검객은 말이 없는 만큼 검이 많았다. 남궁세가의 절기가 새벽 어둠 속에서 은빛 부채처럼 펼쳐졌다. 패검삼십육로(覇劍三十六路)의 변형. 정통이 아닌 방계의 검이되, 방계이기에 오히려 상대의 예측을 벗어나는 초식이 있었다.

호위는 화산의 검만을 알았다. 남궁의 검은 화산과 뿌리가 달랐고, 변초의 방향이 달랐다. 읽히지 않는 검 앞에서 호위의 발이 처음으로 흔들렸다.

그러나 절정은 절정이었다. 남궁린의 검이 어깨를 노릴 때마다 호위의 검이 정확히 반 박자 앞서 막아섰다. 실력의 차이가 아닌 내공의 차이. 남궁린의 기가 한 겹이라면, 호위의 기는 세 겹이었다. 쌓인 세월이 달랐다.

팽팽했다. 아니, 팽팽해 보였다. 그러나 시간이 흐를수록 남궁린이 불리해질 것은 분명했다.

그때.

바람 소리보다 얇은 것이 어둠을 갈랐다.

서령란의 암기(暗器)였다.

작고 가는, 눈에 보이지 않는 침 하나. 그것이 호위의 등 뒤, 정확히 좌측 견갑 아래를 찔렀다. 깊이 박히지는 않았다. 호위가 입고 있는 내갑(內甲)이 끝을 막았을 것이다. 그러나 박히지 않아도 충분했다. 등 뒤에 무언가가 닿았다는 감각, 그것이 호위의 검을 찰나 멈추게 했다.

한 박자.

남궁린에게는 그것으로 족했다.

남궁세가의 검이 호위의 멈춘 검 아래를 파고들었다. 검 끝이 허리를 스치며 올라가 팔뚝을 베었다. 호위가 이를 악물었으나 검을 쥔 손이 벌어졌다. 남궁린의 두 번째 검이 망설이지 않았다. 수평으로 그은 검이 호위의 옆구리를 깊이 갈랐다.

호위가 무릎을 꿇었다.

남궁린이 뒤를 돌아보지 않았다. 시선은 이미 한백강 쪽을 향하고 있었다.

한백강의 상대 — 마지막 남은 호위는 이제 사면이 열린 것을 알았다. 동료 셋이 쓰러졌다. 혼자였다. 한백강의 검에 섞인 이물이 내공을 좀먹고 있었고, 뒤에서는 남궁린이, 더 뒤에서는 서령란의 암기가 기다리고 있었다.

그러나 호위는 물러서지 않았다. 현무진인이 가르친 검은 물러서는 법을 담고 있지 않았다.

호위의 검이 마지막 변초를 펼쳤다. 크고 넓은 궤적이었다. 한백강을 밀어내고 돌파하려는 — 아니, 도관 안쪽으로 들어가려는 의지가 담긴 검이었다. 사형을 지키겠다는 칼.

진무한이 옆에서 들어왔다.

소검 한 줄기가 호위의 변초를 가로질렀다. 크고 넓은 궤적의 한가운데를, 가장 얇은 선 하나가 꿰뚫었다. 호위의 검이 궤도를 잃고 비틀거렸다.
