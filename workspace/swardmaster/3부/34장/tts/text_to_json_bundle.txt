===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_5_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

================================================================================

5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

제34장-묵허(默虛)의 제안

봄의 끝자락이었다.

산 아래로 내려갈수록 바람이 달랐다. 화산의 봉우리에서는 아직 서늘한 기운이 옷깃을 파고들었으나, 중턱을 지나 관도로 접어들면 볕에 데운 흙냄새가 코끝을 간질였다. 들꽃이 한창이었다. 이름 모를 자잘한 꽃들이 길섶을 메우고, 그 위로 나비 두어 마리가 날았다. 봄의 마지막 달답게, 세상은 피어날 만큼 피어나 있었다.

진무한은 걸었다.

등에는 검을 졌다. 검집에 넣은 채로. 발걸음은 빠르지도 느리지도 않았으나, 한 걸음 한 걸음이 정확했다. 경공을 쓰지 않았다. 서두를 이유가 없었고, 서두르지 않아야 할 이유가 있었다.

세 점은 고립했다.

그것이 지난 한 달간 한 일의 요약이었다. 두 번째 판의 통로 세 곳을 끊었다. 인수당의 대역, 월영루의 잔당, 그리고 청해로 향한 황도영의 연락선. 셋 모두 완전히 제거한 것은 아니다. 다만 고립시켰다. 물줄기를 끊으면 뿌리가 마른다. 뿌리가 마르면 가지가 흔들린다. 그것이 진무한이 전생에서 배운 것이었다.

그러나 다섯은 재편 중이었다.

끊긴 세 점의 빈자리를 메우듯, 보이지 않는 손이 움직이고 있었다. 화산 안에서 두 갈래, 바깥에서 세 갈래. 아직 형체는 잡히지 않는다. 하지만 기운이 달라졌다. 산 아래 주막에서 마주치는 떠돌이 검객의 수가 늘었고, 이대의 순찰 보고에 사소한 빈칸이 생기기 시작했다. 누군가 판을 다시 짜고 있다. 끊은 것보다 더 빠르게.

진무한은 그것을 알고 있었다. 알면서도 걸었다.

객잔이 보였다.

어머니의 객잔이었다. 진무한이 봉록을 보내기 시작한 뒤, 어머니는 밭일과 삯바느질을 놓았다. 대신 산 아래 작은 읍내에서 객잔을 열었다. 크지 않은 곳이었다. 방이 넷, 마당에 평상 하나, 부엌에서는 늘 된장 끓이는 냄새가 났다. 어머니가 직접 국을 끓이고, 고용한 아낙 둘이 방을 치웠다.

문 앞에 서자, 안에서 어머니의 목소리가 들렸다. 투숙객에게 밥을 권하는 소리였다. 평범한 목소리. 평범한 하루. 진무한은 잠시 그 소리에 발을 멈추었다.

전생에, 이 목소리는 열일곱에 끊겼다.

아사.

그 한 글자를 떠올릴 때마다 가슴 한 편이 싸늘해진다. 회귀한 뒤 처음 어머니를 찾아갔을 때, 마당에서 빨래를 널고 있던 어머니의 등을 보았다. 그때 진무한은 검을 잡는 손이 처음으로 떨리는 것을 느꼈다. 지금은 떨리지 않는다. 대신, 이 목소리가 계속 들려야 한다는 사실이 검을 쥐는 이유 중 하나로 박혀 있을 뿐이었다.

안으로 들어서지 않았다.

서찰이 왔다는 것을 이미 알고 있었다. 이틀 전, 이대의 연락 경로를 통하지 않은 서찰 하나가 이 객잔에 도착했다. 어머니에게 직접 전해진 것이 아니라, 객잔 앞 느티나무 아래 돌 틈에 꽂혀 있었다. 어머니의 눈에 띄지 않을 자리. 그러나 진무한의 눈에는 띄는 자리.

서찰의 내용은 짧았다.

단오. 달맞이 바위. 혼자. 검은 가져오되 뽑지 마라.

글씨가 단정했다. 붓을 세워 쓴 해서체. 먹의 농도가 고르고, 획의 끝이 둥글었다. 무인의 글씨가 아니었다. 무인은 필압이 일정하지 않다. 내공이 깊을수록 획의 시작이 무겁고 끝이 가볍다. 이 글씨는 달랐다. 처음부터 끝까지 같은 힘. 글을 쓰는 데 익숙한 사람. 혹은, 무공의 기운을 완벽하게 감추는 사람.

진무한은 서찰을 다시 접어 품에 넣었다.

단오까지 사흘.

달맞이 바위. 화산 서쪽 줄기에서 벗어나, 관도를 따라 반나절을 걸으면 나오는 절벽이다. 바위 하나가 달을 향해 고개를 든 것처럼 솟아 있어 그 이름이 붙었다. 인적이 드물다. 주변에 마을이 없고, 사냥꾼도 잘 가지 않는다. 절벽 아래로 계곡이 깊어 소리가 가라앉는 곳.

혼자.

검은 가져오되 뽑지 마라.

두 가지 뜻이 있었다. 첫째, 싸움을 원하지 않는다. 둘째, 싸움이 되지 않는다. 전자라면 대화를 원하는 것이고, 후자라면 경고였다. 어느 쪽이든, 상대가 자신의 무력에 대해 상당한 자신감을 갖고 있다는 뜻이었다.

진무한은 생각했다.

이 서찰을 보낸 자는 누구인가. 어머니의 객잔 위치를 안다. 진무한이 이곳에 들를 시기를 안다. 이대의 연락 경로를 피하면서도 진무한의 눈에 띄는 방식을 택했다. 적이 아니라는 의미인가, 적이면서도 자신감이 있다는 의미인가.

셋 중 하나. 노인의 세력. 환의 세력. 혹은, 그 어디에도 속하지 않는 제삼의 존재.

진무한은 객잔 지붕 위로 시선을 올렸다. 기와 끝에 참새 한 마리가 앉아 있었다. 저물녘의 빛이 참새 깃에 스며들어, 갈색이 금빛으로 보였다.

가야 했다.

함정이든 아니든, 이 서찰은 무시할 수 없는 정보를 담고 있었다. 어머니의 위치를 아는 자가 있다. 그것만으로 충분했다.

단오.

아침 안개가 산줄기를 감싸고, 계곡에서 올라오는 습기가 발목까지 차올랐다. 진무한은 관도를 벗어나 산길로 접어들었다. 사람의 발이 밟지 않은 풀이 무릎 높이까지 자라 있었고, 그 사이로 이슬이 바짓단을 적셨다.

걸으면서 주변을 살폈다.

기척이 있었다. 삼백 보 밖. 따라오는 것이 아니라, 먼저 와서 기다리는 기운이었다. 숨기고 있으나 완전하지 않다. 아니, 완전하지 않은 것이 아니라 일부러 느끼게 한 것일 수도 있었다.

서령란이었다.

진무한은 발을 멈추지 않았다. 서령란이 왜 이곳에 있는지는 생각할 필요가 없었다. 그녀는 그녀의 이유로 움직인다. 마교 방외 지파의 소성녀. 냉철하되 사람다운 여인. 지난 일들을 겪은 뒤에도, 그녀의 행보는 진무한의 행보와 겹치는 부분이 있었다. 어쩌면 같은 것을 쫓고 있었다. 어쩌면 같은 것에 쫓기고 있었다.

삼백 보.

가까이 오지 않는다는 뜻이었다. 관여하지 않겠다는 뜻이기도 했다. 그러나 거기 있다는 것은, 만약의 경우에 움직일 수 있다는 뜻이기도 했다.

진무한은 걸었다.

달맞이 바위가 보이기 시작했다.

절벽 끝에 솟은 바위. 하늘을 향해 비스듬히 기울어진 그 형상이, 아침 안개 속에서 유난히 크게 보였다. 바위 표면에는 이끼가 덮여 있었고, 그 위로 햇살이 비스듬히 내려앉아 초록이 빛났다.

바위 아래에 사람이 앉아 있었다.

노인이었다.

머리가 반백이었다. 흰 것이 검은 것보다 많으나, 아직 검은 것이 남아 있었다. 옷은 수수했다. 짙은 남색의 포. 문파의 휘장도, 강호의 표식도 없었다. 허리에 검이 없었다. 손에도 무기가 없었다. 두 손을 무릎 위에 올려놓은 채, 안개 너머를 바라보고 있었다.

눈이 마주쳤다.

노인의 눈이 깊었다. 깊다는 표현이 부족했다. 우물을 들여다보는 것 같았다. 바닥이 보이지 않는 우물. 그러나 물이 맑아서, 빠져들 것 같으면서도 두렵지는 않은. 그런 눈이었다.

미소가 있었다.

입꼬리가 살짝 올라가 있었다. 세상의 무게를 알면서도 웃을 수 있는 얼굴. 혹은, 세상의 무게를 알기에 웃는 얼굴. 진무한은 그 차이를 구분할 수 없었다. 전생에서도, 그런 종류의 미소를 읽는 데는 자신이 없었다.

「왔구나.」

목소리가 낮았다. 탁하지 않고 맑았다. 나이에 비해 기운이 실려 있었으나, 내공을 과시하는 울림은 없었다. 말 한마디를 내뱉는 데 힘을 쓰지 않는 사람. 혹은, 쓰는 힘조차 느끼지 못할 만큼 깊은 사람.

진무한은 열 걸음 밖에 섰다.

검은 등에 졌다. 뽑지 않았다. 서찰의 요구대로.

「서찰을 보낸 것이 당신입니까.」

노인이 고개를 끄덕였다.

「묵허(默虛)라 하지. 이름이라 하기엔 오래 쓴 것이고, 호라 하기엔 스스로 붙인 것이라.」

묵허.

진무한은 그 이름을 되새겼다. 들은 적이 있었다. 전생에서가 아니라, 이생에서. 매화 아래 노인. 첫 번째 판. 환과는 별개의 기둥. 강호의 어둠 속에서, 노인의 판과 나란히 서 있되 겹치지 않는 또 하나의 그림자.

전생에는 만난 적이 없다.

아니, 만났을 수도 있다. 다만 그때는 이 얼굴을 몰랐고, 이 이름을 몰랐을 뿐이다. 전생의 진무한은 판의 존재조차 몰랐다. 검만 들었다. 검으로만 세상을 베었다. 그러니 놓친 것이 많았다. 놓친 것 중에 이 노인도 있었는지 모른다.

「자리에 앉거라. 아침이 길다.」

진무한은 움직이지 않았다.

「왜 어머니의 객잔에 서찰을 두었습니까.」

묵허의 미소가 변하지 않았다.

「네가 올 곳이 거기밖에 없어서.」

「이대에 전할 수도 있었을 것입니다.」

「이대의 눈이 모두 네 편이냐.」

짧은 물음이었으나, 그 안에 담긴 것은 무거웠다. 이대의 눈이 모두 네 편이냐. 진무한은 대답하지 않았다. 대답할 수 없었다. 이대의 서열 이십삼 번째. 그 자리가 안전한 자리인지는, 진무한 스스로도 확신하지 못했다.

묵허가 다시 말했다.

「앉아라. 서서 하기엔 긴 이야기다.」

진무한은 다섯 걸음을 더 걸어, 바위 앞에 섰다. 그리고 앉았다. 검은 내려놓지 않았다. 등에 진 채로. 뽑지도, 내려놓지도 않는다. 그것이 진무한이 택한 거리였다.

묵허가 안개 너머를 바라보았다. 산 아래로 읍내의 지붕이 희미하게 보였다. 연기가 피어오르고 있었다. 아침밥을 짓는 연기. 평범한 아침의 풍경.

「현무가 너를 의식하기 시작했다.」

진무한의 눈이 미세하게 좁아졌다.

현무. 현무진인. 전대 장문. 호, 환(還). 병사를 위장한 산 자. 두 번째 판의 중심.

「의식이라 함은.」

「네가 세 곳을 끊었지. 인수당, 월영루, 청해의 연락선. 그것이 환의 귀에 들어갔다. 환은 조심스러운 자다. 조심스러운 자가 한번 눈을 돌리면, 그 시선은 거두어지지 않는다.」

묵허의 목소리에는 감정이 없었다. 사실을 진술하는 어조. 그러나 그 사실 자체가 무거웠다.

환이 진무한을 의식하고 있다.

그것은 곧, 진무한이 더 이상 판 밖의 존재가 아니라는 뜻이었다. 지금까지 진무한은 판 위의 돌을 하나씩 치우는 자였다. 그러나 환이 진무한을 인식한 이상, 진무한 자체가 판 위의 돌이 되었다. 치우는 자가 아니라 치워지는 자.

「알고 있었습니다.」

진무한이 말했다. 거짓은 아니었다. 세 점을 고립시킨 뒤, 주변의 공기가 달라진 것을 느꼈다. 눈에 보이지 않는 시선이 등 뒤에 붙었다. 직접 확인한 것은 아니다. 그러나 전생에서 삼십오 년을 살며 쌓은 감각이 말하고 있었다. 누군가 보고 있다.

묵허가 고개를 돌려 진무한을 보았다.

「알고 있었다면, 왜 멈추지 않았느냐.」

「멈출 수 없었습니다.」

「멈출 수 없었다. 좋다. 그렇다면 하나 묻겠다. 혼자 갈 수 있겠느냐.」

진무한은 대답하지 않았다.

묵허가 이어 말했다.

「환은 한 세대를 준비한 자다. 백 년은 아니더라도, 수십 년. 네가 세 점을 끊었다 하나, 그것은 가지를 친 것이지 뿌리를 벤 것이 아니다. 다섯이 재편되고 있는 것은 네 눈에도 보이겠지.」

보였다.

진무한은 고개를 끄덕이지 않았다. 그러나 부정하지도 않았다.

묵허의 시선이 진무한의 등에 진 검을 스쳤다.
